# Contributing to SolenixAI projects

Thanks for helping. This applies to every repo in [SolenixAI](https://github.com/SolenixAI) unless the repo has its own guide.

## Before you start

- **Small fixes** (typos, docs, clear bugs): open a pull request directly.
- **Bigger changes**: open an issue first and describe the problem, so we agree on the approach before you write code.

## Pull requests

- Keep each PR focused on one change.
- Explain what changed and why, and how you checked it works.
- Update the docs when behavior changes.
- By contributing, you agree that your work is licensed under the repo's license (usually Apache-2.0).

## Questions

Open an issue, or email [hello@solenix.dev](mailto:hello@solenix.dev).

Everyone taking part follows our [Code of Conduct](CODE_OF_CONDUCT.md).
