# Security policy

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

- Preferred: use **Report a vulnerability** on the repo's **Security** tab (GitHub private vulnerability reporting).
- Or email [hello@solenix.dev](mailto:hello@solenix.dev) with "Security" in the subject.

Include what you found, how to reproduce it, and the impact you expect. We aim to reply within 3 business days and will keep you updated until it's fixed. We're happy to credit you once a fix is released.

## Supported versions

Security fixes go into the latest release of each project.
